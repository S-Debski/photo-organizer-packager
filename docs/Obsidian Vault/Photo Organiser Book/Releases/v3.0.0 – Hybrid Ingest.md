## Frozen Behaviour

- Source browsed in place; copied only at import — [[07 - Pre‑Import Workflow]]
- Sources: cards + external drives by default; disks, network, any folder — [[12 - Sources (Cards, Drives, Folders)]]
- Culling: keep / reject / unculled; resumes for the same photos only — [[13 - Culling Sessions]]
- Thumbnails: disk‑cached previews; RAW via embedded preview; all RAW types listed
- Cameras & lenses: per photo
- Locations: per folder or all folders; saved; saved places — [[06 - Mapping]], [[14 - Saved Places]]
- Import: shoot title + date + layout with preview; copy‑only; no overwrite; no partial files — [[Organize – Behaviour & Guarantees]]
- GPS to copies: JPG EXIF with refs, RAW XMP sidecars — [[11 - Post-Organize (Metadata Mutation)]]
- Send to phone via adb — [[15 - Send to Phone]]
- Standalone Windows / macOS apps, tray / menu‑bar, bundled ExifTool — [[16 - Packaging & Runtime]]

## Fixed Regressions (vs v2.8)

- EXIF read silently failed on Windows (cp1252 decode) and in the windowed exe (stdin handle)
- Start Import imported the whole card regardless of the kept/all choice
- Write‑GPS wrote to source card files; west longitudes stored as east
- Thumbnail list capped at 100 files and `.raf`‑only
- Shoot‑title import UI lost (June); routes never registered
- CORS allowed any website to read local files via the photo proxy
